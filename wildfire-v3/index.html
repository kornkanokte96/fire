SENSOR DETECTION TIMELINE

จากสัญญาณเซนเซอร์สู่แนวไฟลาม

กำลังคำนวณ…

ลมจากสถานีจำลองและสมมติฐานของฉากนี้

สถานีประเภทลมจาก → ไปความเร็วอุณหภูมิ / RH

สุ่มลมตั้งต้นแต่ละฉาก 0.8–5.0 m/s และทิศ 0–360° จากนั้นให้ลมเปลี่ยนต่อเนื่องตามเวลาและสถานี ค่า PM2.5 / CO / อุณหภูมิ / RH เป็นสัญญาณสังเคราะห์ทั้งหมด ไม่ใช่ค่าจากอุปกรณ์จริง Reference Station จำลอง PM2.5 เท่านั้น ส่วน Fusion / AQ ใช้ PM2.5 และ CO ตามชุดที่เสนอ Existing Sensors สมมติการรองรับ PM สำหรับเดโม

ภูมิประเทศใช้ DEM ของ Network Plan แบบหยาบ เชื้อเพลิงสมมติเป็นเนื้อเดียวกัน ไม่จำลองความชื้นเชื้อเพลิงที่วัดจริง การกระโดดข้ามแนวด้วยสะเก็ดไฟ ไฟเรือนยอด หรือการดับไฟ เวลาตรวจจับและพื้นที่ไฟลามใช้พรีเซ็นต์การทำงานของระบบเท่านั้น

หลักการอ้างอิง: NWCG — Fire behavior inputs · US Forest Service — Conditional burn probability

Access classificationแยก road / track / path และอ่าน surface, tracktype, access, barrier จาก OSM เมื่อมีการระบุ
Suppression supportแสดง fire station, hydrant, spring/water และ helipad เฉพาะรายการที่มีการ map ใน OSM; การไม่พบไม่ได้แปลว่าไม่มีในพื้นที่จริง

ข้อมูลที่ใช้และขอบเขตของเดโม

WILDFIRE V.03 ใช้เครือข่ายที่วางแผนล่าสุด N01–N21 และ Existing Sensors 3 จุดร่วมกันบนแผนที่ 2D และ 3D ภูมิประเทศสำหรับวางแผนใช้ Copernicus DEM GLO-90 ผ่าน Open-Meteo ส่วนภาพ 3D ใช้ Terrarium DEM และ Esri World Imagery ถนนและทางเดินมาจาก OpenStreetMap

ฉากไฟลามใหม่สุ่มลมตั้งต้น 0.8–5.0 m/s ให้เปลี่ยนต่อเนื่องตามเวลาและสถานี ค่าเซนเซอร์และเวลาตรวจจับทั้งหมดเป็นข้อมูลจำลอง สีความน่าจะเป็นคือสัดส่วนจาก 24 ฉากที่ลามถึงพื้นที่ภายในเวลาที่เลือก หลังสมมติว่าจุดเริ่มต้นติดไฟแล้ว

ชุด Reference / Super Station จำลอง PM2.5 โดยไม่มี CO ชุด Fusion และ AQ จำลอง PM2.5 / CO ตามอุปกรณ์ที่เสนอ Existing Sensors สมมติการรองรับ PM สำหรับการสาธิต เพราะยังไม่มีรายละเอียดอุปกรณ์ครบ เกณฑ์ ΔPM2.5 >25 µg/m³ และ ΔCO >0.2 ppm เป็นเกณฑ์ทดลอง ไม่ใช่เกณฑ์ที่สอบเทียบกับอุปกรณ์จริง

Historical Replay ในแผนที่ 2D ยังใช้ลมอ้างอิงเดิม 261° → 81° เพื่อเทียบเครือข่าย ส่วนฉาก 3D ใช้ลมสุ่มใหม่ ทุกพิกัดและเส้นทางเป็นข้อมูลช่วยวางแผน ต้องตรวจสอบหน้างานก่อนใช้งานจริง
